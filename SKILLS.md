# Установленные скиллы в проекте

Источник: `skills-lock.json`

| Скилл | Описание |
|-------|----------|
| **clerk-nextjs-patterns** | Advanced Next.js patterns — middleware, Server Actions, caching with Clerk |
| **find-skills** | Помогает находить и устанавливать agent skills |
| **frontend-design** | Создание production-grade фронтенд интерфейсов с высоким качеством дизайна |
| **nextjs-app-router-patterns** | Next.js 14+ App Router: Server Components, streaming, parallel routes |
| **nextjs-best-practices** | Next.js App Router принципы, Server Components, data fetching |
| **nextjs-supabase-auth** | Интеграция Supabase Auth с Next.js App Router |
| **nextjs-turbopack** | Next.js 16+ и Turbopack: incremental bundling, FS caching |
| **shadcn** | Управление shadcn компонентами: добавление, поиск, отладка, стилизация |
| **supabase** | Работа со всеми продуктами Supabase (Database, Auth, Edge Functions, Realtime, Storage, и т.д.) |
| **supabase-postgres-best-practices** | Postgres оптимизация и best practices от Supabase |
| **web-design-guidelines** | Проверка UI на соответствие Web Interface Guidelines |

## Как активировать скилл

```xml
<use_skill>
<skill_name>название_скилла</skill_name>
</use_skill>
